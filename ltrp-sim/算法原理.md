# LTRP 当前算法原理说明

> 本文件描述的是**当前仓库里真实在跑的代码**(`backend/sim/`),以它为准。
> 注意:`README--new.md` 写的是另一套(集中式 Dijkstra + ACO + RCSPA)设计,与现有代码不符,不要照它理解。

---

## 一、这是什么东西(一句话)

一个**月球熔岩管里"去中心化"通信网的仿真沙盘**:没有中央大脑,每根道钉只靠"能看到的邻居"自己做决定,自己组网、自己绕路、断了还能自愈。

- 世界:一条蜿蜒的地下熔岩管,4~6 个大腔室(大厅)靠窄喉道(喉咙)连起来,管里有巨石挡住信号。
- 节点:1 个主基站、约 30 根道钉(中继)、2 枚探针(面包屑撒布载体)、2 辆月球车(会移动)。
- 后端 Python(FastAPI + WebSocket)每 0.3 秒推一帧快照,前端 React + Canvas 画出来。
- **开局是"库存 + 撒布"**:道钉初始离线堆在基站旁,由探针向右推进沿途撒布上线(面包屑部署)。

## 二、核心算法分步讲(简单话)

### 1. 邻居发现(信标,beacon)
每个节点定时广播一条"打招呼"消息,内容是:我是谁、还剩多少电、我认识哪些邻居、我到基站有多远。
对方收到后,如果信号够强(SNR 够高),就把它记进自己的邻居表。

- **SNR(信噪比)**:信号相对噪声的清晰度,越高越好。门槛是 12dB(已有链路容忍 4dB 衰落,防抖)。
- 收到的 SNR 会做平滑(新旧按 7:3 加权),避免一个瞬时波动就把邻居踢了。

### 2. 判死
连续 3 个信标周期(约 2.7 秒)收不到某个邻居的消息,就认定它死了/失联,从邻居表里删掉。

### 3. 路由(DSDV,分布式 Bellman-Ford)
本质就是"**问邻居怎么走最近**":

- 每个节点根据邻居广播来的"距离表",用「走到邻居的代价 + 邻居说的剩余代价」更新自己到基站的最短路径和"下一跳"。
- 每 tick 松弛 3 轮,几十个 tick 内全网收敛到稳定路由。
- **防环**:用"水平分割"——不把某个目的地的信息回传给"本来就要往那走"的邻居,抑制两跳内的环路;再加代价上限与跳数上限,抑制计数到无穷。

- **单跳代价公式**:`12 + 距离/40 + 8`,再叠加低 SNR / 高 BER / 双端队列积压的惩罚项。

### 4. 能量保护(DLER 双模式度量)
节点按电量自动降级,让全网活得久:

| 电量 | 状态 | 行为 |
|---|---|---|
| >40% | 正常 NORMAL | 正常转发 |
| 20%~40% | 保护 PROTECTED | **退出中继**,只收发自家的数据 |
| <20% | 垂危 DYING | 强制休眠保命 |
| ≤0.5% | 宕机 DEAD | 死亡 |

选路时两条规则二选一:
- 存在"安全路径"(沿途最弱节点电量 ≥40%)→ 选**代价最小**的;
- 否则 → 选**剩余电量最足**的那条,牺牲一点跳数换全网寿命。

### 5. 割点自识别(2 跳视图)
节点在心里问一句:"**把我删掉后,我的邻居们还互相连得通吗?**"
连不通,说明自己是关键节点(卡喉咙的位置),就锁定常开、别睡觉。连续 3 次投票一致才确认(防抖)。

- **割点(cut vertex)**:删掉它网络就会断成两半的关键节点。

### 6. 容断(存储-携带-转发,DTN 思想)
如果某片区域和基站断了(比如喉道被摧毁):

1. 断联节点的数据先打包存起来,这种暂时没路可走的数据叫**束(bundle)**。
2. **月球车**按巡逻路线来回跑,经过时"顺路搬运"这些束(叫**摆渡 ferry**)。
3. 回到有信号的地方,再把束吐给有路由的邻居,多跳回传。

### 7. 地月回传(潮汐锁定)
月球被潮汐锁定,始终同一面朝向地球:地球恒可见,不存在升起/落下/遮挡。数据一旦汇聚即可实时回传,无缓冲窗口。

### 8. 激光无线充电(母-子多跳 bucket-brigade)
地表可控核裂变 → BASE-00 巨型储能电池 → 沿**含睡眠节点**的能量树逐跳下发:
每跳"光伏转换 → 自用优先 → 富余一部分留存本地电池、其余反射给下游",并按**子树缺电需求加权**分配,
使深处的长链得到更多注入,能量能递送到管尾。睡眠只关无线电,不切断能量中继。

### 9. 首次部署(面包屑)
两枚探针**上下分带**从基站向右推进:PROBE-1 走中心线上带(+`CARRIER_OFF`)、
PROBE-2 走下带(-`CARRIER_OFF`),腔室里撒成上下两股互为冗余的链,窄喉道处两带自然并线;
探针合速度恒 ≤ `MOVE_V`(10cm/s,含横向+纵向+兜底夹紧的全部位移)。
每前进 ≥ 动态间距撒下一颗库存道钉,落点经**三轮防放置求解**:与上一颗
(或任一已路由节点)视距可达、离岩壁/巨石保距、与既有道钉保间距;
盲区(急弯/巨石群,连基站都被挡)自动退化为 40~80px 短跳链,沿走廊爬过弯道后恢复正常间距。
未探明区域在前端显示为灰色迷雾。

## 三、主循环(tick)流水线

每 0.3 秒跑一轮(物理步长 `dts = dt × time_scale`),按顺序做 13 件事(`engine_ext/step.py`):

| # | 阶段 | 代码 |
|---|---|---|
| 0 | 探针面包屑部署(未撒布节点保持离线) | `deploy.py` |
| 1 | 月球车巡线(部署完成后才出动) | `rover.py` |
| 2 | 邻接表刷新 | `build.py` |
| 2.5 | 激光无线充电(能量树逐跳下发) | `power.py` |
| 3 | 节点自愈移动 | `heal_logic.py` |
| 4 | 信标交换(引擎只投递,节点本地处理) | `step.py` |
| 5 | 邻居判死 + 割点自识别 | `step.py` |
| 6 | DSDV 路由松弛(3 轮) | `protocol.py` |
| 7 | 休眠调度(腔室冗余道钉轮值休眠,喉道边界和割点不休眠) | `sleep.py` |
| 8 | 能量消耗 + 状态机 + SEU/宕机播报 | `nodes.py` |
| 9 | 数据面:遥测生成 → 逐跳转发 / 束化 | `traffic.py` |
| 10 | 月球车摆渡 | `ferry.py` |
| 11 | 地月回传(恒可见) | `traffic.py` |
| 12 | 统计 + 自愈播报 → 推快照给前端 | `stats.py` |

## 五、术语表(专业词备注)

| 词 | 解释 |
|---|---|
| 信标 beacon | 节点定时广播的"打招呼"信号 |
| SNR 信噪比 | 信号相对噪声的清晰度 |
| 水平分割 split horizon | 防环技巧:不把路由信息回传给它的来源方向 |
| DSDV | 一种分布式最短路径协议,靠邻居间反复交换距离表收敛 |
| DLER | 双模式能量路由度量:安全路径走最短,否则走最省电 |
| 割点 cut vertex | 删掉后网络会断开的关键节点 |
| 束 bundle | 无路可走时暂存的数据包 |
| 摆渡 ferry | 移动节点(月球车)顺路搬运数据 |
| 存储-携带-转发 | 容断网络思想:存下来→带着走→再转发 |
| EWMA | 指数加权平均,越新的数据权重越大,用来平滑 SNR |
| DTO | 数据传输对象:跨模块传递的强类型结构 |
